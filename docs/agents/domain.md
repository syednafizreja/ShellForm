# Domain Docs

This repository uses a single-context layout.

Before exploring, read:

- `GLOSSARY.md` at the repository root if it exists
- `docs/adr/` for decisions that touch the area being worked

Do not create a glossary or ADR upfront. A domain-modeling skill may add them when terms or decisions need resolution.

Use the glossary's terms where they exist. Surface an ADR conflict explicitly rather than silently overriding it.
