# ShellForm v0.2.0 (16 Nov 2026)

ShellForm v0.2.0: the finalised research record.

No result changed from v0.1.0. Every data and figure file of the v0.1.0 record in `results/` and `figures/` is unchanged (new files only: `results/verify_*`, Fig. 6, Fig. S1; `figures/README.md` lists them), and the record is still the freeze run at tag `freeze-2026-11-09` with ShellBench `v0.3.0`.

## New in this release

- Verification checks V1-V5 (sphere buckling benchmark, mesh convergence, force density residual, membrane energy share, formwork bound), Fig. 6 and Fig. S1.
- Manuscript tables built by script from the record (`paper/tables/`, LaTeX in `paper/tables/latex/`), and a map from every reported number to its source (`paper/numbers.md`).
- Long-term reproduction: `requirements.txt`, `environment-lock.yml`, `SHA256SUMS` for every result and figure, and `docs/REPRODUCE.md`.
- Landing-page README, `CONTRIBUTING.md`, `docs/CHANGELOG.md`, and the design explorer live at <https://syednafizreja.github.io/ShellForm/explorer/>.
